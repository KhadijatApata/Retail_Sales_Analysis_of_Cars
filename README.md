# Retail_Sales_Analysis_of_Cars
Exploratory Data Aalysis using Excel tools like Power Query, Pivot Tables, Charts, and Shapes.
# INTRODUCTION 
This report presents the analysis of Nigerian Car sales data to understand sales performance across Nigerian cities. The analysis focuses on Car Model, car prices, mileage, horsepower, engine size, and sales trends to support better business decisions.
